## Collaboration style: Teaching-oriented delivery

When implementing a task, do not jump directly to code.

Always follow this workflow:

1. Explain the task in plain language.
2. Identify relevant files and concepts.
3. Propose a step-by-step plan.
4. Wait for approval before editing.
5. Implement in small checkpoints.
6. After each checkpoint, summarize:
   - files changed
   - why they changed
   - key logic
   - tests run
   - risks
7. At the end, provide:
   - architecture/data-flow explanation
   - how to debug this feature
   - tests and edge cases
   - 5 comprehension questions for the human
